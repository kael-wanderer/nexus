# Nexus release walkthrough

Candidate version/build/commit: __________  macOS / Mac: __________  Date / tester: __________
Displays and audio devices: __________  Notes / issue links: __________

Run on the installed candidate with a real keyboard and pointer. Set the shortcuts in Settings → Shortcuts if needed and use their displayed values; do not assume historical defaults. Record Pass, Fail, or Blocked in every row, with details and issue links in Notes. Blocked is not a pass. Restore changed permissions and settings afterwards. Every applicable row must pass; an owner must explicitly decide whether to release with any blocked row.

| Step | Expected result | Pass / Fail / Blocked | Notes |
|---|---|---|---|
| In a text editor, type a marker. Invoke Search, type `safari`, select Safari with arrows and Return. Return to the editor; invoke Search again, type `safari`, press Escape, then type another marker without clicking. | Selection activates Safari; cancelling returns focus to the editor and the second marker appears there. | | |
| In the editor invoke the window switcher; type part of a window title, select a card with arrows and Return. Return to the editor, reopen, type a filter, press Escape to clear it and Escape again to close; type a marker without clicking. | Matching cards appear; Return activates the chosen window; Escape clears then closes and typing returns to the editor. | | |
| With two windows including a minimised one, open the switcher; use arrows to wrap, click a card, reopen and click its background. Reopen and use ⌘W on a disposable window. | Minimized window is marked; navigation wraps; clicking activates or dismisses as appropriate; ⌘W closes the selected disposable window. | | |
| Open a full-screen app, put the pointer on each display in turn and invoke the switcher. With VoiceOver enabled, inspect a card and toolbar. | The panel opens on the pointer's display above the full-screen app without changing Spaces; cards and controls have meaningful labels. | | |
| In the switcher, ⌘-click two cards from different apps and choose Add Stack. Close one listed window while the switcher is open and try selecting it. | A group appears in the bar; a vanished window does not crash or activate an unrelated window. | | |
| In Settings search type `group`; press Return. Repeat and click a result. Search for `zzzznomatch`. | Results include Applications per group and Opened group shows; Return and click open the indicated tab and clear the field; an empty state appears for no match. | | |
| In Finder create a folder with two files. Drag it onto the bar, then click its row. | The folder pins and its stack shows the two files. | | |
| Drag a running app into pinned, reorder pinned apps, drag one into running, then drag an app onto another to create a group and into an existing group. | Preview follows the pointer; committed order, pin state and group membership match each drop. | | |
| Start a reorder, then cancel the drag with Escape; repeat with the target removed while dragging. Fill a group to its configured capacity and try dropping another app onto its centre. | Cancellation preserves stored order; disappearance causes no crash or unrelated mutation; a full group does not accept another member. | | |
| Minimise a Finder window, inspect the row before Trash, then click it. | A minimized-window row appears and clicking restores the window. | | |
| Hover an app with two windows. Use New Window on Safari and on a utility without a matching menu item. Choose Quit, cancel the confirmation, then reopen and confirm Quit for a disposable app. | Two cards and header controls appear; New Window works where supported and does nothing otherwise; cancel leaves the app running and confirm quits it. | | |
| Play media, hover the now-playing row, then change Settings → Behavior → flyout size through small, medium and large. | Artwork, title, artist, scrubber and transport controls appear; both flyouts resize without restarting. | | |
| Revoke Accessibility in System Settings while Nexus is open; open the switcher and an app flyout, then restore the grant. | The switcher shows its permission gate, no stale window cards appear, other supported functions remain usable, and windows return after permission is restored. | | |
| Deny Screen Recording, open the switcher and dismiss its offer; reopen it. Grant Screen Recording and reopen again. | With denial, icons still work and the dismissed offer stays dismissed; with the grant, previews can appear. | | |
| Click the clock, move to another month, close and reopen; toggle clock and volume off and on in Settings → Bar. | Calendar opens beside the row and reopens at the current month; toggled rows disappear and return without relaunch. | | |
| Move volume with the Nexus slider, keyboard keys and system slider; right-click the volume row twice. Switch from speakers to headphones as default output and move the slider. | Glyph tracks volume, mute becomes Unmute, and the slider controls the current headphones. | | |
| Select an HDMI output with no settable volume as the default output. | Nexus hides the volume row instead of showing an ineffective slider. | | |
| With a second display connected, open a flyout, unplug the display, then reconnect it. | Remaining display stays usable; panels reappear on the appropriate display without stale or stranded flyouts. | | |
| Put the Mac to sleep, wake and unlock it, then invoke Search and open a bar flyout. | Bar and interactions recover without relaunch or lost focus. | | |
