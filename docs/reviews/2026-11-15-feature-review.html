Nexus feature review

15 November 2026 · what to improve, remove and add · judged by how often a feature is used, not by how long the list gets

Short answer. Nexus already has more features than a Dock needs. The best return is not new features: it is four Dock habits Nexus still lacks, one unfinished headline feature, and cutting about a dozen options nobody changes after the first day. Five additions, five improvements, eleven removals.

How this was judged

  • A feature stays or is added only if a normal user would use it at least once a quarter. Each item carries its expected frequency.
  • Sources: FEATURES.md, ROADMAP.md, the source, and the settings of the copy installed on this Mac (read only, nothing written).
  • The installed copy is one person's use. It is evidence, not proof: a setting left at its default may be unused or simply right.

Add

Five items. All are things the system Dock or Spotlight already does, so a user who switches to Nexus loses them today.

1. Drop a file onto an application to open it daily

Drag a file from Finder onto a row in the bar and it opens in that application. FEATURES.md lists this as out of scope. It is the most used Dock gesture after clicking, and the drag code for pinning already receives the drop.

2. Hide and Hide Others daily

The row menu has Quit, Force Quit and Show All Windows but no Hide. Add Hide, Hide Others, and the Dock's ⌥-click (hide the application being left). Uses NSRunningApplication.hide(): no permission.

3. Calculator in the search palette daily

Type 128*1.07, see the answer, Return copies it. Every launcher has it and it is the reason many people open one. Build it on a small arithmetic parser that accepts digits, operators and brackets only. Do not pass typed text to NSExpression: its format strings can call functions.

4. Newest first in a folder stack daily

The Downloads stack is the Dock's second most used feature, and it is useful because the file just downloaded is at the top. Stacks today list folders first, capped at 60. Add a sort choice per stack (name, date added) and default Downloads to date added.

5. Export and import settings quarterly

Pins, groups, folders and every preference live in one defaults key. A new Mac, a reinstall or a bad experiment loses them. Two buttons in Settings › About: save to a file, load from a file. The format is already versioned and migrated, so import is a decode. Validate the file like any untrusted input: size limit, version check, repaired(capacity:) on the pins.

Considered and not recommended: window tiling (macOS 15 does it natively), clipboard history (Bugler has it), weather, battery and network widgets (the menu bar has them), calendar events in the clock (needs a Calendar permission for a glance the menu bar gives free), recent documents per application (no public interface that is reliable), workspaces, plugins, AI. None passes the frequency test without duplicating something the Mac already does well.

Improve

1. Finish Dock replacement or stop presenting it as the point daily

Nexus is described as a Dock replacement and the owner runs it with replacement off. Find out why in one sitting: missing gestures (Add 1, 2 and 4 are likely causes), fear of losing the Dock on a crash, or the release checklist never run. Then either fix what blocks it or reword the product as "a bar beside the Dock". Everything else in this review matters less than this.

2. Updates and notarisation quarterly

Both are blocked on things outside the code: a paid Developer ID and somewhere to publish a version number. Without them every release reaches other Macs by hand with a right-click to open. A GitHub release already exists (v0.2.0), and its releases feed is a hosted endpoint: an update check can read it over HTTPS with no server of its own.

3. Media timeline off the main thread daily, when music plays

Player position is read through AppleScript on the main thread. A slow or hung player freezes the whole bar. Move the script to a serial background queue with a timeout. Already agreed for after 0.2.1.

4. Window switcher default shortcut daily

The owner rebound it to ⌥Tab. Make ⌥Tab the default and keep ⌃⌥W out of it. Also confirm the checklist row on keyboard focus scrolling into view, since a switcher that loses its highlight is not usable by keyboard.

5. Two copies of one application monthly, for some users

Recorded as a known limit today. Not worth a rewrite of identity. Worth one cheap step: when a second copy launches, follow its window events too, so its windows are at least not stale.

Remove

Eleven items. Each is either a second way to do something, a setting changed once and never again, or off by default and off in practice. Removing them shrinks Settings from nine tabs toward six and removes code that tests have to keep alive. Stored keys stay readable so old configurations still load.

Keep, though they look removable: Start menu (on in use; the only place for Sleep, Restart, Shut Down, Log Out), Settings search (cheap, and more useful the fewer times Settings is opened), opened group as a list (on in use), minimized windows, clock, volume, now playing, reserved space, hide over full-screen applications.

Suggested order

  1. 0.2.1: run the release checklist, fix what fails. No feature work.
  2. 0.3.0, "a Dock you can switch to": Add 1, 2 and 4, Improve 1 and 4. Then turn Dock replacement on and live with it for two weeks.
  3. 0.3.x, "less": the Remove table, in two or three commits, each with its settings rows and tests.
  4. 0.4.0: Add 3 and 5, Improve 2 and 3.

Removals are the owner's decision: several are features asked for earlier. Nothing in this review has been changed in the code.
