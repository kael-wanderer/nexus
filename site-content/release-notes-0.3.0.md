# Nexus 0.3.0

Apple silicon, macOS 14 or later.

## New

- Drop files on an app's row to open them there.
- Sort folder stacks by Date Added.
- Hide and Hide Others in the row menu; ⌥-click hides the current app.
- Online guide, from the menu bar menu and Settings.
- Update check in Settings › About.

## Improved

- Smoother bar and fading popovers.
- Music players can no longer freeze the bar.
- Window switcher opens with ⌥Tab.
- Faster search; "vsc" finds VisualStudioCode.

## Fixed

- Setup no longer removes pinned apps, groups or folders.
- Search arrow keys pick the row you see.
- Hidden Dock always comes back.
- Many smaller fixes.
