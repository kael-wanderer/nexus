---
title: Keyboard shortcuts
summary: Every shortcut Nexus listens for, and how to change them.
---

Nexus has three global shortcuts, which work in any app. The rest work only while a Nexus panel is open.

## Global shortcuts
| Keys | Does | Change it in |
|---|---|---|
| <kbd>⌥</kbd><kbd>Space</kbd> | Opens the [search palette](../search/search.md) | Settings ▸ **Shortcuts** ▸ **Open search** |
| <kbd>⌃</kbd><kbd>⌥</kbd><kbd>Space</kbd> | Puts the keyboard on the [bar](../windows/keyboard-control.md) | **Focus the bar** |
| <kbd>⌥</kbd><kbd>Tab</kbd> | Opens the [window switcher](../windows/window-switcher.md) | **Open the switcher** |

To change one, click its box in Settings ▸ **Shortcuts** and press the new keys. A shortcut needs at least one of <kbd>⌘</kbd>, <kbd>⌥</kbd> or <kbd>⌃</kbd>. Press <kbd>⌫</kbd> to reset a shortcut to its default and <kbd>Esc</kbd> to cancel. The bar and switcher shortcuts have an on and off switch above them.

If two shortcuts are the same, Settings shows a red warning and only the first one works.

> [!NOTE]
> <kbd>⌘</kbd><kbd>Space</kbd> belongs to Spotlight. To use it for Nexus, turn off Spotlight's shortcut in System Settings first. <kbd>⌃</kbd><kbd>F3</kbd> and <kbd>⌘</kbd><kbd>Tab</kbd> also belong to macOS and never reach Nexus.

## In the search palette
| Keys | Does |
|---|---|
| <kbd>↑</kbd> <kbd>↓</kbd> | Move through results |
| <kbd>Return</kbd> | Run the selected result |
| <kbd>⌥</kbd><kbd>Return</kbd> | Run the secondary action, such as opening a file's folder |
| <kbd>⌘</kbd>1 to <kbd>⌘</kbd>9 | Run the numbered result |
| <kbd>⌃</kbd>1 to <kbd>⌃</kbd>6 | Pick a scope: **Everything**, **Applications**, **Files & Folders**, **Files**, **Folders**, **Settings & Actions** |
| <kbd>⇥</kbd> / <kbd>⇧</kbd><kbd>⇥</kbd> | Next or previous scope |
| <kbd>Esc</kbd> | Back to **Everything**, then close |

## In the window switcher
| Keys | Does |
|---|---|
| Arrow keys | Move between cards |
| <kbd>⇥</kbd> or the switcher shortcut again | Next card |
| <kbd>Return</kbd> | Go to the focused window |
| <kbd>⌘</kbd><kbd>W</kbd> | Close the focused window |
| <kbd>⌘</kbd>-click | Select a card, for **Add Stack** |
| <kbd>Esc</kbd> | Clear the filter, then close |

## When the bar has the keyboard
| Keys | Does |
|---|---|
| <kbd>↑</kbd> <kbd>←</kbd> / <kbd>↓</kbd> <kbd>→</kbd> | Previous or next row |
| <kbd>Home</kbd> / <kbd>End</kbd> | First or last row |
| <kbd>Return</kbd> or <kbd>Space</kbd> | Open the focused row |
| <kbd>Esc</kbd> | Give the keyboard back |

## Mouse with a key
| Keys | Does |
|---|---|
| <kbd>⌥</kbd>-click an app on the bar | Switches to it and hides the app you were in |
| <kbd>⌥</kbd>-drop a folder on an app | Opens the folder in that app |

## From macOS
- <kbd>⌥</kbd><kbd>⌘</kbd><kbd>D</kbd> hides or shows the macOS Dock, whatever Nexus thinks. Settings ▸ **Dock** mentions it.
